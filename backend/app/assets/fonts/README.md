# Bundled fonts

Burned into rendered creations by the template renderer (libass). All are licensed under the
SIL Open Font License 1.1 (text in `OFL.txt`), which allows bundling them in software and
using them in commercial videos. Files are the Latin subsets served by Fontsource (Montserrat
comes from the upstream project, whose family name libass can match), plus a Devanagari
fallback so Hindi captions render.
